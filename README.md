# Codex 模式聊天

在 Codex 模式中显示 ChatGPT 聊天入口、统一聊天记录与手动刷新。

## 功能

- 在 Codex 新对话页的内容区顶部显示与原生首页一致的“聊天 / 工作”模式选择器
- 从原生首页状态识别模式，兼容顶部产品菜单隐藏和首页订阅结构变化
- 在 Codex 模式中显示 ChatGPT 与 Codex 的统一任务列表
- 为置顶、项目内任务、最近记录与自定义分组中的任务显示“聊天”或“Codex”悬浮来源标签
- 保留客户端原生筛选、导航和项目操作
- 为最近任务增加手动刷新按钮

## 安装

下载或克隆本仓库后，将本目录作为本地功能包导入 Codex Tweaks。首次安装后需完成编译并手动启用。

## 权限与安全

- Renderer：读取并临时包装 Codex 的 React 首页与侧栏组件，复用原生撰写器状态和任务同步服务
- Node：未使用
- 网络：不自行请求网络资源；手动刷新会触发 Codex 自带的 ChatGPT 任务同步

## 兼容性

- Codex Tweaks API：v3
- 已测试平台：macOS
- 已知限制：依赖 Codex 首页、统一侧栏、React Fiber、客户端资源和任务目录读取器的内部结构

## 开发

此包没有 npm 依赖。使用 `mise run check` 检查 JavaScript 语法，在 Codex Tweaks 中重新编译后，验证聊天与 Codex 模式切换、两类任务、筛选导航、手动刷新及停用时组件恢复。

首页切换器通过原生订阅与 `home-composer-mode-v1` 偏好设置识别状态，不依赖固定 Hook 序号、资源文件名或私有模块导出。模式可用性继续由客户端的账户和工作区权限决定。
